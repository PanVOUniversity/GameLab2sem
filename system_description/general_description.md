## Общее описание Игровой Системы

Представленная система является пошаговой стратегической игрой, разработанной на языке C++. Игра включает в себя игровое поле, различных юнитов с уникальными характеристиками и способностями, специальные типы полей, заклинания, а также логику для взаимодействия игрока (человека) и компьютерного противника (AI).
