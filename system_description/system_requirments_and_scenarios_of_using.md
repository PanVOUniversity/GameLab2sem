# Требования к системе и сценарии использования

## Общие требования
Система должна предоставлять интерактивный интерфейс командной строки для игрока.

## Функциональные требования
- **Инициализация игрового поля** заданного размера с размещением специальных объектов (холмы).
- **Создание игровых сущностей:** двух игроков (человек и AI) с начальным запасом маны.
- **Размещение юнитов** на игровом поле.
- **Пошаговый игровой процесс** с возможностью выполнения игроком различных действий:
    - Перемещение юнитов по полю в пределах их дистанции передвижения.
    - Атака вражеских юнитов или крепостей в пределах дистанции атаки юнита.
    - Создание новых юнитов за ману в специально отведённых зонах.
    - Применение заклинаний за ману с различными эффектами (нанесение урона, снижение характеристик, создание специальных полей).
    - Использование специальных способностей юнитов (например, создание инженером крепостей или мин, молитва жреца для создания защитного поля).
- **Учет и применение эффектов специальных полей** (крепости, холмы, мины, горелые поля, госпитализированные поля, экранированные поля).
- **Обработка получения урона** юнитами и их уничтожение при достижении нуля здоровья.
- **Реализация логики AI** для принятия решений о действиях (создание юнитов, перемещение, атака, применение заклинаний, строительство).
- **Отслеживание условий победы и поражения** (уничтожение всех юнитов противника, захват всех крепостей, исчерпание маны и юнитов, пропуск ходов).
- **Управление ресурсами игрока** (мана).
- **Отображение состояния игрового поля и информации об игре** (карта юнитов, карта полей, правила).

## Сценарии использования
- **Начало новой игры:**
    - Игрок запускает игру, происходит инициализация поля и игроков.
- **Ход игрока:**
    - Игрок получает информацию о текущем состоянии игры, просматривает доступные команды, принимает решение о действиях (перемещение, атака, создание, заклинание, способность, строительство) и вводит соответствующие команды.
    - Игрок может выполнять несколько действий в свой ход, пока у юнитов есть очки воли или достаточно маны.
    - Игрок завершает ход командой `END`.
- **Ход AI:**
    - Система выполняет действия для AI игрока на основе его внутренней логики.
- **Взаимодействие юнитов:**
    - Юниты перемещаются по полю, атакуют друг друга или крепости, применяют способности.
- **Взаимодействие с полями:**
    - Юниты входят на специальные поля и получают соответствующие эффекты.
- **Применение заклинаний:**
    - Игрок или AI тратят ману для применения заклинаний на целевые клетки или юниты.
- **Строительство инженером:**
    - Инженер тратит волю и игрок тратит ману для создания новых специальных полей (крепостей, мин, ловушек).
- **Завершение игры:**
    - При выполнении условий победы или поражения игра заканчивается, и объявляется результат.
