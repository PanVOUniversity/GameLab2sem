GameLab2sem
A turn-based strategy game with AI and CLI interface.
Классы
Классы с их кратким описанием.
 CArcherRanged unit with variable attack distance (Archer)
 CBombedFieldField that acts as a trap and explodes after a timer or when triggered by a unit (Bombed Field)
 CBombSpellSpell that creates a bombed field (trap) at a target location (Bomb)
 CBurnedFieldField that deals damage to units each turn for a limited duration (Burned Field)
 CCannonStationary ranged unit with directional fire ability (Cannon)
 CCurseSpellSpell that reduces a unit's abilities (Curse). Damage to zero
 CEngineerUtility unit that can build special fields (Engineer)
 CFieldRepresents a field (tile) on the game board. Base class for all field types
 CFireballSpellSpell that deals damage to a target unit (Fireball)
 CFortressRepresents a Fortress field on the board, which provides defense and can be captured or destroyed
 CGameDataHolds the main game data: board and players
 CHillRepresents a Hill field on the board, which provides a defense bonus
 CHospitalFieldField that heals units each turn (Hospital Field)
 CInfantryMelee unit with counter-attack ability (Infantry)
 CManaMineFieldField that generates mana for the owner each turn (Mana Mine Field)
 CMorogSpellSpell that changes owner of unit on the field
 CPlayerRepresents a player in the game (human or AI)
 CPriestSupport unit that can create shielded fields (Priest)
 CShieldedFieldField that provides a temporary shield to units (Shielded Field)
 CSpellAbstract base class for all spells in the game
 CTeleportSpellSpell that teleports a unit to a new location (Teleport)
 CUnitRepresents a unit in the game (base class for all units)
